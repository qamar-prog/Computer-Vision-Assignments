# Computer Vision Labs

A collection of practical Computer Vision laboratory exercises and
implementations developed as part of the AI4002 – Computer Vision course.

The repository covers fundamental image processing and computer vision
techniques using Python, NumPy, OpenCV, and related libraries.

## 📚 Course

- **Course:** Computer Vision
- **Course Code:** AI4002
- **Language:** Python
- **Primary Tools:** NumPy, OpenCV, Matplotlib
- **Format:** Jupyter Notebooks

## 🚀 Topics Covered

The labs explore fundamental concepts including:

- Image representation and visualization
- Grayscale image processing
- Image histograms
- Intensity transformations
- Logarithmic and power-law transformations
- Image enhancement
- Thresholding
- Otsu's thresholding
- Image segmentation
- Filtering and convolution
- Edge detection
- Feature extraction
- Morphological operations
- Other fundamental Computer Vision techniques
